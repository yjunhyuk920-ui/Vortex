# Derive a Finite-Word Discontinuous Bilinear Source

Type: research
Status: in-progress
Blocked by: Derive an Implicit Nonlinear Bilinear Query Source

## Question

Can automatic preprocessing of an unchanged dense Q4 checkpoint compile a
non-exhaustive finite-word data structure that answers the exact declared
Bilinear Cross Residual `r^T W u` below the registered 405B build, state,
operation, logical/physical traffic, and fallback budgets by using a mechanism
that genuinely escapes Exact-Field Bilinear Path Collapse?

The first deliverable is one concrete constructor and query equation, not a
word-RAM family name. It must freeze the finite input and output semantics,
word size, bitwise/modular/floor/rounding instructions, persistent layout,
table growth, address generation, every probe, hot state, verification,
misses, fallback, and service-life amortization. It may not use an exhaustive
activation-answer table, target-future trace, checkpoint modification,
approximate-only answer, free SIMD factor, unbounded-word operation, hidden
dense preprocessing per query, or a schedule that is merely a static field
arithmetic circuit.

Before E1, either derive a favorable finite target-scale equation and the
cheapest untouched falsification Gate, or reject the declared constructor at
E0. Do not run a model, assign EXP-085, build a backend/kernel, contact the
Ubuntu server, or download a larger checkpoint until a construction exists
and survives E0.
