## Answer

The arbitrary Cartesian population has not been invalidated: real causal
query rank remains unmeasured. The shape-only threshold is nevertheless now
closed for one concrete execution interface, the **Causal Bilinear Span
Ledger**. A favorable full two-byte factor scan over all 883 registered 405B
matrix instances fits the complete p50 traffic equation only through span
dimension `B=23`. At that boundary it consumes `1.159413233%` traffic,
`0.281295494%` operations, and `2.104879502 GiB` component state; `B=24`
already exceeds the `1.185185185%` traffic allowance before fallback.

For any held-out query population with certified exact rank `R`, even the best
future-aware post-hoc `B`-dimensional span misses at least `max(0,R-B)` rows.
The frozen 36-row last-down population can afford only four weighted
fallbacks, so certified rank `28` rejects every `B<=23` factor-scan ledger.
The E1 Gate uses the pinned Qwen3.5-0.8B checkpoint and EXP-076 prompt split,
24 build rows, 36 disjoint evaluation rows, prompt-only side rank 16, three
registered odd primes for independence certificates, and an exact rational
witness for every claimed hit. Modular nonincrease alone receives no hit
credit.

This is not a Core Candidate. The Gate grants the current residual-pair
extractor and local result source for free; the known general decision-dual VJP
is dense, and native BF16/Q4 linear-combination semantics remain unproved. A
population pass may open only a paid extractor/native-semantics Gate. A rank-28
or greater result closes this factor-scan ledger without a parameter sweep.
