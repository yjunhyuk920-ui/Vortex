# Break the Bilinear Cross-Residual Barrier

Type: task
Status: resolved
Blocked by: Find a Post-Atlas Causal Information Source

## Question

Is there a checkpoint-derived, lossless query mechanism that obtains the exact
Bilinear Cross Residual `r^T W u` for arbitrary prompt-dependent causal
residual pairs with a complete finite 405B equation below the registered
operation, traffic, state, build, verification, miss, and fallback budgets?

The mechanism must avoid dense dynamic forward/transpose construction, full
static direction enumeration or scan, training, checkpoint modification,
target-future leakage, an external proof without a local result source, and
hidden dense discovery. First seek either a scoped lower bound in an explicitly
declared preprocessing/query model or a concrete exact data structure with a
finite representation and constructor. Do not assign an experiment number or
start model/hardware work until one route closes E0.

## Answer

A finite scoped lower bound closes the strongest direct separable extension of
the Causal Residual Atlas.

The declared `Matrix-Local Separable Residual Code` chooses arbitrary binary
linear row/column covers per matrix, stores the complete lossless image pair,
and grants every term except the raw coordinate cross residual for free. The
image pair has exact rank `a*n + m*b - a*b`. A finite sphere-cover witness at
code rate `3/10` and residual radius `3/16`, combined with coefficient-weighted
Markov accounting, gives the registered 405B bound:

```text
complete binary hot grant             8 GiB
minimum raw cross probes              6,141,198,336
minimum raw cross fraction            1.52104775688%
complete p50 allowance                1.18518518519%
bound / allowance                     1.28338404487x
```

The proof charges no code lookup, decoding, cached-term arithmetic, image
reads, verifier, fallback, KV/runtime state, or physical movement. Eight
independent controls pass, including exhaustive GF(2) identity and independent
small image-rank reconstruction.

Decision:

```text
REJECT_MATRIX_LOCAL_SEPARABLE_LINEAR_RESIDUAL_CODE_AS_CORE
DO_NOT_REOPEN_ATLAS_WITH_LARGER_OR_COVERING_BASES
KEEP_NONSEPARABLE_GLOBAL_OR_CAUSALLY_RESTRICTED_SOURCE_OPEN
```

This is not a universal bilinear-query impossibility theorem. It assumes
matrix-local image state, arbitrary independently selectable per-matrix query
pairs, and coefficient probes. Joint cross-matrix advice, nonlinear and
word-packed data structures, and real causal reachability remain open.
