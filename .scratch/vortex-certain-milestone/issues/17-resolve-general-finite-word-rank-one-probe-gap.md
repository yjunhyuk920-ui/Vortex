# Resolve the General Finite-Word Rank-One Probe Gap

Type: research
Status: claimed
Blocked by: Derive a Finite-Word Discontinuous Bilinear Source

## Question

For an arbitrary unchanged bounded-word dense matrix, does there exist an
automatic globally nonlocal nonlinear data structure that answers every exact
rank-one numerical query r^T W u below the registered VORTEX construction,
persistent-state, operation, logical/physical traffic, address, verification,
miss, fallback, and service-life budgets?

The declared model must fix 32-bit and 64-bit word semantics, native numerical
output semantics, allowed bitwise/modular/floor/rounding operations, global
advice size, preprocessing time and traffic, query adaptivity, address
generation, every probe, hot state, and failure behavior. It must exclude
unbounded words, target-future traces, checkpoint modification, approximate
answers, external provers, exhaustive activation-answer tables, and free
query computation that would be charged on the target machine.

A resolution requires one of two finite deliverables:

1. a concrete constructor, layout, and exact query equation that survives the
   complete 405B E0 budget and exposes the cheapest untouched E1 falsification
   Gate; or
2. a correctly scoped lower bound or finite adversarial certificate that
   covers the declared globally nonlocal nonlinear probe model despite the
   global 8 GiB advice grant.

A named word-RAM/cell-probe family, a Boolean nonemptiness theorem, a local
truth table, Mailman/Four-Russians packing, native rounding called free state,
or another static arithmetic circuit is not a deliverable. Current systematic
linear and direct-sum bounds are too weak to close this model and may not be
promoted into a universal impossibility claim.

Do not run a model, assign EXP-085, build a backend/kernel, download a larger
checkpoint, contact the private Ubuntu server, or begin hardware calibration
until one of the two E0 deliverables exists.
