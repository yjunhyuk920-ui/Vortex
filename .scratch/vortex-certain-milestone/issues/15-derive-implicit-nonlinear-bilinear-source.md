# Derive an Implicit Nonlinear Bilinear Query Source

Type: research
Status: open
Blocked by: Bound Query-Adaptive Exact Code Unions

## Question

Can automatic preprocessing of an unchanged dense checkpoint compile a
lossless implicit nonlinear data structure that answers exact Bilinear Cross
Residual queries `r^T W u` below the registered 405B traffic, operation, state,
build, and fallback budgets without materializing or scanning a trace-built
basis of query directions and scalar answers?

The first deliverable is one concrete constructor and query equation, not a
named data-structure family. It must identify where the exact answer
information resides and charge preprocessing, persistent representation,
causal selection, probes, logical/address traffic, operations, hot state,
verification, misses, and fallback. It may not assume an uncharged membership
oracle, external prover, target-future trace, exponential table, checkpoint
modification, approximate-only answer, static linear arithmetic circuit,
separable/global linear advice already covered by prior bounds, or dense-
equivalent discovery hidden in preprocessing.

Before E1, either derive a favorable finite target-scale equation plus the
cheapest untouched falsification Gate, or reject the declared construction at
E0. Do not run a model, assign EXP-085, build a backend/kernel, contact the
Ubuntu server, or download a larger checkpoint until such a construction
exists and survives E0.
