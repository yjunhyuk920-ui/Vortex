# Architecture Gate 0 certificate — VORTEX-WAVE-1

Evidence level: **E0 architecture + E1 observed mechanism input**

This document defines one complete model-wide candidate and populates the 405B memory, traffic, and compute equations before further backend work.

It does **not** declare the flagship target feasible. The analytic envelope closes, but the required repair-amortization mechanism is not yet measured.

The machine-readable source of truth is `architecture_gate0_budget.json`, generated by:

```bash

```

## Complete candidate execution path

`VORTEX-WAVE-1` has four paths.

### 1. Hot session capsule

Every attention and MLP projection is represented by a fixed-rank session operator image:

```text
input x
  -> rank-32 session coordinates
  -> INT8 operator image
  -> approximate hidden contribution
```

The model-wide linear capsule includes Q/K/V/O, gate/up/down, and the LM head. Embeddings use a 4,096-row session cache with row-level cold loading for misses.

The capsule is generated automatically by the runtime. It is not a trained student model and requires no user calibration command.

### 2. Compressed attention path

Reading and computing against the entire 405B KV history would already exceed the 4B-class compute target. The normal path therefore uses:

- rank-64 INT8 attention summaries for the older context;
- an exact BF16 recent window of 128 tokens;
- exact host-side KV retained for repair.

The summary path proposes attention outputs. It cannot commit a token by itself.

### 3. Weight-stationary block proposal

The hot capsule proposes a block of future positions. The planned first falsification block size is 256 positions.

The runtime keeps a candidate dependency graph and does not commit positions merely because the hot path produced them.

### 4. Exact selective repair and certification

Cold BF16 weights and exact KV remain authoritative. Unresolved token decisions request only the weight/KV regions whose residual bounds can still cross a final logit boundary.

A selected cold tile is applied to all unresolved positions in the block while resident. After each repair sweep, the runtime commits only the stable causal prefix.

The quality contract is:

```text
hot path proposes
certificate commits
cold exact data resolves uncertainty
full exact fallback remains available
```

Therefore the candidate can preserve exact greedy semantics only if the future certificate and repair implementation is sound. That implementation is not yet present.

## Resource equations

The gate uses:

```text
M_hot + M_kv + M_work + M_repair <= 8 GiB
B_hot + B_cold / E <= 1.2 * B_4B
C_hot + C_cold / E <= 1.2 * C_4B
```

where:

```text
E = committed tokens / full-model-equivalent repair fraction
  = A / rho
```

`A` is committed tokens after a repair batch and `rho` is the fraction of a full exact model/KV sweep consumed by that batch.

This form prevents a partial repair from being counted as a full stream and prevents a large speculative block from being counted as committed output.


This is a target threshold, not an observed result.

## Falsification mechanism

The next implementation is a real-operation block-repair harness, not another offline hook analysis.

It must replace selected operations in a real pretrained 1B–3B causal model and record for every repair batch:

```text
proposed positions
committed causal-prefix positions A
exact weight bytes read
exact KV bytes read
rho = exact bytes / full exact sweep bytes
E = A / rho
hot bytes/token
peak device memory
wall-clock/token
exact-token agreement
```

Build and evaluation prompts must be disjoint and include Korean, English, code, mathematics, structured output, and long-form continuation.

### Promotion threshold

The candidate is promoted to E2 work only when all are true:

```text
exact greedy token agreement = 100% for committed tokens
measured E >= 600 on the real-model experiment
measured device state follows the <= 8 GiB projection
hot-path traffic and compute remain within the analytic envelope
representation growth remains bounded across unseen prompts
```

The threshold is 600 rather than the calculated minimum 491.3 to retain measurement margin.

### Immediate rejection conditions

Reject or redesign `VORTEX-WAVE-1` when any is true:

```text
E < 300 after the planned repair/block sweeps
rank-32 capsule error forces near-full repairs on unseen prompts
compressed attention requires full KV repair for most positions
capsule/device state scales beyond the 8 GiB envelope
end-to-end operation replacement cannot preserve the declared quality mode
```
