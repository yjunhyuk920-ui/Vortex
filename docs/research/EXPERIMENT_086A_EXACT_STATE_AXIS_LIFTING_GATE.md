## Question

Can a block of exact causal Transformer activations be represented by a very small
shared exact recurrence program along the **state/token axis**, so that one base
matrix product plus a small union of dyadic residual atoms replaces an independent
dense product at every future position?

This is the cheapest favorable Gate for one concrete transition-microprogram
language. It does not build a drafter, a CUDA kernel, or a complete executor.

## Why this changes execution dependency

EXP-085A fused `gate -> SiLU * up -> down` across the intermediate-neuron axis,
but even its unavailable exact-contribution oracle needed every one of 192 pages.
The failure showed that independent page selection destroys signed cancellation.

EXP-086A rotates the proposed sharing axis. For one exact BF16 activation stream

```text
x_0, x_1, ..., x_(K-1)
```

it asks whether future states can be generated by exact recurrence microprograms
from earlier states plus a small residual:

```text
x_t = P_t(x_<t) + r_t.
```

If `P_t` is an exact linear combination of already evaluated complete vectors,
then for a fixed projection `W`:

```text
W x_t = P_t(W x_<t) + W r_t.
```

Only the residual requires new checkpoint interaction. The Gate also grants an
impossible coordinate-wise predictor whose parent may differ by coordinate.
That arm is not deployable; it is a strict favorable upper bound. Failure of that
arm rejects every more constrained predictor in this registered language.

## Exact finite-word encoding

Every BF16 value is decoded as an exact signed dyadic integer:

```text
value[t,j] = scaled[t,j] * 2^coordinate_exponent[j].
```

The coordinate exponent is the minimum exact exponent observed in the block.
All recurrence selection and residual construction are performed in signed
integer arithmetic. Nonfinite values, int64 overflow, or excessive exponent
range fail closed.

## Registered recurrence language

For state index `t`, candidates are:

```text
zero
copy any earlier complete state
2*x_(t-1) - x_(t-2)
x_(t-1) + x_(t-2) - x_(t-3)
3*x_(t-1) - 3*x_(t-2) + x_(t-3)
```

Two frozen selectors are measured.

### Vector selector

One candidate vector is selected for the whole state. This arm has an actual
algebraic reuse interpretation because the matching prior projection outputs can
be combined before evaluating the residual.

### Coordinate oracle

Each coordinate receives its independently cheapest candidate. Applying the
resulting mixed-parent vector is granted free, together with all masks, router
metadata, and reconstruction. This can only help the candidate and is not a
runtime construction.

The selected residual minimizes, in order:

```text
nonzero coordinates
signed integer popcount
integer magnitude bits
deterministic predictor name
```

## Favorable signed-atom cost

For every residual coordinate, split its exact signed integer into powers of two.
Across the whole block, one positive and one negative atom at each bit position
is charged only once per coordinate, regardless of how many future states use it.

One exact base-vector product is charged. Every one of the following is free:

- future target tokens and target activations;
- coordinate-wise mixed-parent application;
- binary masks and address generation;
- broadcasting one atom across all block positions;
- recurrence output combinations;
- metadata storage;
- native reduction-order repair;
- all attention, norms, embedding, LM head, KV, and non-MLP work.

For stream width `D`, block length `K`, and signed atom union size `U`:

```text
f_stream = (D + U) / (K*D).
```

Gate/up share one input stream, while down uses the post-SwiGLU stream:

```text
f_mlp = (2*f_input + f_down_input) / 3.
```

The projected whole-model operation fraction is:

```text
f_op = llama405_mlp_parameter_share * f_mlp.
```

A complete MLP weight stream read once per perfect accepted block gives the
separate favorable weight fraction:

```text
f_weight = llama405_mlp_parameter_share / K.
```

The joint screen is `max(f_op, f_weight)`.

## Controls

The implementation must pass all of the following before a checkpoint verdict:

- equal BF16 words map to equal exact dyadic integers;
- identical states collapse to one base pass;
- exact linear recurrences produce zero residual after their seeds;
- the coordinate oracle is never worse than the vector selector;
- gate/up/down accounting uses two shared-input streams and one down-input stream;
- nonfinite input fails closed;
- deterministic result regeneration produces the same core hash.
