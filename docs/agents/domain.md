# Domain Docs

VORTEX is a single-context repository. Read root `CONTEXT.md` before naming a
new mechanism, evidence claim, Gate, or milestone. Read applicable research
contracts and ADRs before changing an architectural decision.

`CONTEXT.md` is vocabulary only. Implementation details belong in experiment
contracts, root research ledgers, and source code. System-wide irreversible
architectural decisions may be recorded under `docs/adr/` when a real tradeoff
requires one.
