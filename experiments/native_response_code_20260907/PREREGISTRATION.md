Question: can a whole native nonlinear block be replaced by explicitly generated
input-side codes and XOR output atoms, without assuming smooth real equivalence?
This revisits an escape from the prior real derivative theorem, not a larger rank test.

Compare three finite-response executions before admission:
A. Split the actual current input into two halves. Compile exact GF(2) row-space codes
and word payloads. Runtime joins selected atoms; never calls original dense operations.
B. Change from arithmetic composition to finite input pulses: exact Boolean Möbius
coefficients of output words; runtime visits active subsets and XORs their payloads.
C. Change from evaluation to ordered rounding cells: compile contiguous constant-output
runs; current input address finds a run by binary search. No approximate cells.
These use known tools, not three claimed novel scientific discoveries. They are bounded
comparators; three goal-qualifying new principles and a >=10x full-cost route are NOT
established. Table generation is explicit exponential work, never free. Do not build a
large backend or scale to a checkpoint after a toy pass.

Cost screen: if n coordinates have Q bit-distinct values, source table has Q^n evaluations.
For A, L=Q^(n/2), R=Q^(n/2), m outputs, rank r: payload bytes
L*ceil(r/8)+2*m*R*r, plus header and domain. Query payload bytes
ceil(r/8)+2*m*popcount(code), plus domain lookup, input/output and loaded metadata.
Rank is NOT a per-query lower bound: pivot-row codes are one-hot even at full rank.
B dense coefficients cost 2*m*Q^n and visits 2^popcount(address) atoms.
C run storage is K*(4+2*m), plus domain and metadata. Query search/address costs count.
