# Post-main-result check (not preregistered)
After completing the frozen finite-domain study, test the proposed scaling shortcut
of adding independent small-table answers across input coordinate groups. A two-input
SwiGLU with G=U=[1,1], D=[1] provides a native counterexample. This rejects only naive
additive stitching, not all compositions or input-side data structures. Do not label
this case a preregistered success or a universal lower bound.
