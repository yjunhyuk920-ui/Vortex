## Constructed, not merely named

1. **Address-only alias router**: query values are checkpoint independent;
   checkpoint patterns live in logical-to-query-table routing. Exact arbitrary
   GF2 control; 5.31% favorable arithmetic, but explicit registered 64-bit alias
   descriptors total 300.75 GiB.
2. **Patricia pattern synthesizer**: exact compressed row-pattern trie evaluated
   directly against the query. 2.34% favorable event fraction, but one 64-bit
   checkpoint label per edge is about 2x raw binary source before topology and
   memberships on the frozen square realization.
3. **Rank-normal encoded state**: arbitrary rectangular `A W B = J_r` compiler.
   Isolated dense maps become `1/n`, but the fully paid literal transformed AND
   restores both dense maps in the minimal two-projection graph.
