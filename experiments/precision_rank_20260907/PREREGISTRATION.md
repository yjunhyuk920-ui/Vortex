## Three materially different candidate mechanisms
A. Precision-dependent algebra: discard real-rank as the only complexity guide; represent a matrix in Z/(2^K) via automatic local diagonalization W=LDR, evaluate small factor channels, and recover every signed integer output when 2^K>2B. Hypothetical >=10x route: channel count r_K gives r_K(m+n)<=mn/10 with factor bit lengths, construction and movement charged. Cheapest gate: compare r_1 with r_K for the K that actually determines output, not only parity. Unlike prior CRT source which scanned complete residue matrices, this candidate attempts to construct fewer source channels. Need no sparsity of output. Rejected generic low-rank models are not reopened without this altered numeric algebra; novelty of existing local-ring mathematics is not claimed.
B. Nonlinear decoding of a dense bounded vector from a low-dimensional integer/lattice message: arithmetic rank need not lower-bound nonlinear decoders. Concrete base-(2H+1) code and inverse; compare message count with its bit precision, not unit-cost arbitrary integers. Cheapest gate: finite-domain counting plus exhaustive small decoder. No claim this counting is an online read bound with x/side information.
C. Singular-limit (border-rank) bilinear source instead of exact tensor rank: permit a limit of shorter bilinear programs, then attempt exact recovery. Cheapest gate: flattening of the matrix-vector bilinear tensor has rank mn, including border rank. Restriction: W and x are variable, no W-dependent nonlinear preprocessing. Does NOT lower-bound arbitrary fixed-checkpoint algorithms.

Select A for bounded constructor/native-lift test only if numerical sufficiency can be explicit. Do not build a GPU/backend or run huge cases after the rank budget fails. B,C are tiny structural gates, not new target executors.

## Fixed experiments
Shapes n=8,16,32,64,128; seeds 17,29; families random_sign (+/-1), odd_integer (odd values +/-1..255), sylvester (permuted signed Hadamard), constant (all ones, deliberate easy control). 40 matrices. Input |x_j|<=7 integer, 8 vectors per matrix: zero, all +7, all -7, one-hot, alternating +/-7, 3 seeded dense random inputs. No input quantization of an actual model. All coefficients/inputs exactly BF16, sumabs<=n*255*7<2^24, so separately rounded FP32 products/balanced sums are exact integers. Negative-zero inputs excluded. Final BF16 RNE checked separately. No actual SiLU/attention/HF/KV/RNG inference.

B=max_i sum_j abs(W_ij)*7. K=bit_length(2B), modulus=2^K, guaranteeing modulus>2B. Rank profile k=1..K via diagonal valuations obtained at K; independently rerun elimination at each k for n<=16. Certificate W=LDR mod2^K, odd-determinant L,R (invertible mod2); L,R themselves are paid dense construction. Exact ordinary full rank may be certified by determinant mod65521, without interpreting a zero determinant mod65521 as real singularity.

Store nonzero factor channels U=L[:,:r]*D, V=R[:r,:] and a self-contained binary file. Coefficients occupy ceil(K/8) bytes, with bounds/header charged. Query source uses U,V and x, no W. Generic factor query uses dense modular multiplies even if fields are zero; report zero-aware option only if actually implemented (not planned). Do not mistake equivalent modular factor count for a lower bound on every algorithm. Sylvester countercontrol: integer FWHT is an explicitly implemented faster algorithm despite full lifted factor rank.
