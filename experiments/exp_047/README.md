# EXP-047 — Causal Probabilistic Tile Certificate

## Current scope

Phase A/B, evidence ceiling E1.

This experiment tests a finite-population sign certificate over synthetic tile contributions. It does not run a real Transformer, GPU, 405B checkpoint, or Phase D benchmark.

```bash
bash experiments/exp_047/run_current_env.sh
```

## Gate

Promotion to Phase-C design requires:

- zero silent wrong accepts in the current corpus;
- zero fallback/reference mismatches;
- independent bound agreement;
- a positive synthetic cancellation control certified after <=25% tiles at the largest size;
- adversarial controls falling back to all tiles;
- complete provenance and 405B projection fields.

Even a pass remains E1 and does not demonstrate real-model or target-hardware savings.
