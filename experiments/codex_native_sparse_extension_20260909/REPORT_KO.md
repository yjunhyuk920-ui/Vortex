# BF16 제한 실행기 확장 결과

기존 binary 가중치·한 활성 좌표 생산기를 유한 BF16 가중치·두 활성 좌표까지
확장했다. 입력 전체를 검사한 뒤 실제 선택 열과 행별 부호 메타데이터만 읽는다.
원래 FP32 반올림 트리의 결과와 음의 0을 복원하는 범위 제한 증명을 작성했다.

CPU HF의 고정된 작은 합성 모델에서 V projection을 실제로 교체했다. 40단계의
logits·직렬화한 KV 상태와 8개 생성 토큰, 각 샘플의 확률·RNG 전후 상태가
원본과 일치했다. 첫 V 캐시 stride 불일치도 검출·보존한 뒤 수정했다.

이 모델은 입력을 두 좌표에 제한하고 나머지 dense 경로와 logits를 0으로 만든
특수 모델이다. 임의 체크포인트나 모든 continuation의 실행 증명이 아니다.
작은 모델의 선택 계수 읽기는 93.75% 줄지만 행 메타데이터까지 넣으면 87.5%이며,
KV 복사와 실제 Python 객체 비용 등은 추가된다. 전체 비용·속도 목표 통과가 아니다.

O1~O5 OPEN, O6 PARTIAL, THEORY_STATUS=NOT_ESTABLISHED,
HARDWARE_STATUS=NOT_TESTED, CORE_ADMISSION=false를 유지한다.
405B 장비가 없다는 사용자 정보는 하드웨어 제한으로 기록하며 이론 실패나
불가능 증명으로 해석하지 않는다. 다음 핵심은 모든 좌표가 변해도 싼 정확한
전역 dense 생산기/동적 상태를 실제 알고리즘으로 구성하는 일이다.
