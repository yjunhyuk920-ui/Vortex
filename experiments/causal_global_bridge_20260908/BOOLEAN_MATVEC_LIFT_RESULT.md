## 1. Why this route was credible enough to test

Larsen and Williams, *Faster Online Matrix-Vector Multiplication* (SODA 2017,
arXiv:1605.01695), give a deterministic systematic Boolean-semiring cell-probe
data structure with worst-case query complexity

```text
O(n^(7/4) / sqrt(w))
```

for Boolean `Mv`. Chakraborty, Kamma and Larsen, *Tight Cell Probe Bounds for
Succinct Boolean Matrix-Vector Multiplication* (STOC 2018,
arXiv:1711.04467), explicitly describe that previous algorithm as deterministic
and give a faster randomized succinct Boolean upper bound. They also prove
similar systematic lower bounds over `F2`.

The old F-052 record correctly said the Boolean output is not a signed/native
numerical source. The missing question was whether an exact finite lift could
convert that fast Boolean producer into the GF(2) parity primitive used by the
new nonlinear-router and causal-query results. This round answers two concrete
versions of that question.

## 2. Theorem A — an adaptive black-box lift needs `|supp(v)|` Boolean products

Let the only matrix-dependent interface be

```text
B_M(s)[i] = OR_j (M[i,j] AND s[j]).
```

A deterministic lift may choose each later `s` from the target `v` and every
previous complete Boolean product vector. It must return

```text
P_M(v)[i] = XOR_j (M[i,j] AND v[j])
```

for every binary matrix.

Put `T=supp(v)`. On one designated row compare

```text
R0 = indicator(T)
Ri = indicator(T without i),  i in T.
```

Every `Ri` has target parity opposite to `R0`.

For an oracle subset `S`, the designated-row Boolean response differs between
`R0` and `Ri` **iff**

```text
S intersect T = {i}.
```

One query therefore isolates at most one deletion witness. On the deterministic
transcript generated by `R0`, if fewer than `|T|` Boolean products have been
queried then some `Ri` has exactly the same complete transcript but the opposite
required parity. Exact output is impossible on that pair.

Hence

```text
minimum worst-case Boolean-product calls >= |supp(v)|.
```

For full support this is exactly `n`. The matching adversary-family upper
sequence is the `n` singleton queries, so the bound is tight for the frozen
witness family.

### Finite controls

Every distinct query set of size `<n` on the all-ones path was enumerated for
`n<=5`:

```text
n=1       1 short query set checked
n=2       4
n=3      29
n=4     576
n=5  36,457
total 37,067
false determinations 0
```

The complete-result interface returns `n` bits per Boolean product. Thus the
full-support black-box lift alone returns `n^2` Boolean response bits before any
native arithmetic. Composing `n` calls with the Larsen--Williams
`O(n^(7/4)/sqrt(w))` Boolean query implementation gives an
`O(n^(11/4)/sqrt(w))` implementation route, losing rather than retaining its
subquadratic exponent. This composition statement is an upper-cost consequence
for that implementation, not a lower bound against every direct GF(2) data
structure.

## 3. Theorem B — one transformed Boolean product needs exactly `2^d-1` features

The black-box theorem still leaves a stronger escape: transform the checkpoint
row and the query independently into Boolean features so that **one** Boolean
inner product already equals parity.

Allow arbitrary nonlinear feature maps

```text
E   : F2^d -> {0,1}^K
Phi : F2^d -> {0,1}^K
```

and require

```text
a dot v mod 2
  = OR_k (E(a)[k] AND Phi(v)[k])
```

for every `a,v`.

This is exactly a Boolean factorization of the complete GF(2) inner-product
truth matrix. Its Boolean rank is **exactly**

```text
2^d - 1.
```

### Lower bound

The truth matrix contains

```text
(2^d - 1) * 2^(d-1)
```

ones. Consider one all-one rectangle `A x B` and choose `a0 in A`. Let

```text
U = span {a + a0 : a in A}.
```

Every `b in B` is orthogonal to `U`. Because `a0 dot b = 1`, `a0` is not in
`U`, so the affine condition `a0 dot b=1` halves `U^perp`. Therefore

```text
|A| <= 2^dim(U)
|B| <= 2^(d-dim(U)-1)
|A||B| <= 2^(d-1).
```

At least `(2^d-1)` one-rectangles are needed to cover all ones.

### Matching upper bound

Use one rectangle for each nonzero left vector `a`, containing that one row and
all `v` with `a dot v=1`. There are exactly `2^d-1` such rectangles.

Thus the lower and upper bounds match.

### Exhaustive controls

All nonempty left subsets were enumerated for `d<=4`. The largest one-rectangle
sizes were exactly

```text
d=1  1
d=2  2
d=3  4
d=4  8
```

matching `2^(d-1)` in every case.

### Storage consequences

Even granting one stored row-feature bit per feature, the exact lower bounds are:

```text
right width  rows  minimum features             row-feature/source ratio
8             4    255                          31.875x
25           25    33,554,431                   1,342,177.24x
108          25    324,518,553,658,426,...      3.0048014e30x
216          25    2^216-1                      4.8755691e62x
```

For the exact area-5,400 `25 x 216` source used by the causal bridge, a single
Boolean-product feature lift therefore requires

```text
25 * (2^216 - 1)
```

stored row-feature bits before the Boolean data structure itself, query
features, addresses, native values or decoder state.

This theorem permits arbitrary nonlinear `E` and `Phi`; it is not merely a
linear-factorization rejection.

## 4. What remains open — direct GF(2) / native data structures

Neither theorem says that every exact GF(2) data structure is impossible.

The CKL `F2` systematic lower bound states that if `R(M)` has at most `r` side
bits and the query algorithm may probe `R` plus at most `t` raw matrix entries,
then for `n <= r <= n^2/4`:

```text
t * r = Omega(n^3 / log n),
```

and for `r<n`, `t=Omega(n^2/log n)` even for the one-bit vector-matrix-vector
query. This is important lower-bound evidence, but it does **not** numerically
close the VORTEX target once substantial side data is allowed; no hidden
constant is promoted into a target certificate.

The literature search for this round did not find an arbitrary-dense, zero-error
`F2` preprocessing/query upper construction that supplies the missing VORTEX
producer. A 2022 treatment of OMV over `F2` explicitly notes that the Larsen--
Williams improvement relies on the Boolean semiring and reports no better field
algorithm known there. The 2025 Anand--van den Brand--McCarty structural MatVec
upper bounds obtain subquadratic queries for low VC-dimension or matrices close
to that structured class; that is not an arbitrary-checkpoint guarantee.

Absence from this search is not an impossibility theorem. The active Principle-B
object remains a direct, finite, zero-error, globally paid GF(2)/native producer
whose representation and query algorithm do not factor through the two rejected
Boolean lifts above.

## 5. Relation to earlier failures

- This strengthens F-052. The Boolean-semiring source is now rejected not only
  because its output algebra differs, but because exact black-box parity lifting
  has an `n`-call adversary and one-shot arbitrary nonlinear feature lifting has
  exponential Boolean rank.
- It does **not** reopen F-055 separable left/right covering codes, F-076 fixed
  linear functional decoders, response tables, finite-semiring catalogs or
  full-scan packed arithmetic.
- A query-dependent nonlinear sparse functional dictionary or a genuinely
  nonlinear direct GF(2) cell-probe structure remains outside these theorems.
