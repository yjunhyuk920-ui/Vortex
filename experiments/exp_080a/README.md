# EXP-080A runner

This throwaway logic prototype asks whether exact rectangular fast matrix
multiplication can make a perfect future block meet the final target-equivalent
traffic **and** arithmetic fractions. It does not generate future tokens and it
does not reopen the rejected Jacobi, fixed-point, external-draft, or native-MTP
families.

The interactive one-command entry point will be:

```powershell
.deps\exp076-venv\Scripts\python.exe -m vortex_runtime.hyperblock_fmm_prototype
```

The canonical batch command will be registered with the implementation commit.
No checkpoint download, private Ubuntu command, or physical performance claim
is authorized.

Run the canonical batch Gate from an empty output directory:

```powershell
.deps\exp076-venv\Scripts\python.exe experiments\exp_080a\run_experiment.py --output-dir results\exp_080a
```

The runner uses only the Python standard library and committed shape/evidence
JSON. Exact signed-integer Strassen comparisons are embedded controls rather
than a production test suite.
